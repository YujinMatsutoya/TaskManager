# TASK-42: Better task search

As a user I want to search my tasks so I can find things quickly.

Acceptance criteria:
- Search should be intuitive and return relevant results.
- It should handle typos where appropriate.
- Results should be sorted sensibly.
- Search must be case-sensitive so users get exact matches.
- Search should ignore case so users don't have to worry about capitalisation.
- It should work nicely on mobile.
- Searching should feel instant.
